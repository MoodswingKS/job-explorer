# Job-Explorer

For the code assessment FWG

# Stack

- Next.js + App Router
- Typescript
- Tailwind CSS

# How to run?

```bash
npm install
npm run dev
```

localhost:3000

# What's in it

- Functions page in cards
- Search bar
- Filter tools
- URL state
- Refreshing the page does not refresh the filtering
- API routing

# What is not in to

- Details page

If I had more time I would have added that too, and also found a way to fix the load issues.
I chose for the cards as the end-user would probably enjoy a card based system more. But a list would probably be more optimal for the loading time. Finding a way in between the loading time and an enjoyable user experience would be a priority.
